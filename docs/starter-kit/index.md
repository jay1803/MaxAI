# Templates

Copy these and adapt them. Placeholders are in angle brackets.

- [Agent rules file](agents-md.md): a starter `AGENTS.md` for your agents,
  with authority tiers, whitelist, tracker conventions and writing rules.
- [Issue templates](issue-templates.md): decision card, chat task, daily and
  weekly plan, daily agent check, weekly review, skill review, correction
  retro, workflow improvement, project sync.
- [Routine prompts](routine-prompts.md): skeleton prompts for the scheduled
  routines: daily intake, incremental loop, reply watch, recurring-issue
  watchdog, repository sync.
