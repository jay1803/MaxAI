# System

The system has a few parts with clear jobs:

- [Architecture](architecture.md): the components and how a piece of work
  flows between them.
- [Roles](roles.md): which agent owns which kind of signal, so two agents never
  handle the same thing.
- [Authority](authority.md): what agents may do alone, what needs the owner,
  and how autonomy is earned.
- [Task tracker](task-tracker.md): states, fields and conventions that make the
  tracker the single ledger.
